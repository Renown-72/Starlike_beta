# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# event_homing.1  开局：自动殖民 Europa
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
country_event = {
    id = event_homing.1
    hide_window = yes
    is_triggered_only = yes
    trigger = {
        is_ai = no
    }
    immediate = {
        # 在 Homing_Sol 恒星系中，找到 Europa（月球），自动殖民
        every_system = {
            limit = { has_star_flag = Homing_Sol }
            every_system_planet = {
                limit = {
                    is_colony = no
                    is_colonizable = yes
                    has_planet_flag = Homing_Europa
                }
                set_owner = root
                create_colony = {
                    owner = root
                }
            }
        }
        # 首次开局时在恒星系发现异常，为探索叙事埋线
        every_system = {
            limit = { has_star_flag = Homing_Sol }
            create_ambient_object = {
                type = "anomaly_exoplanet_01_ambient_object"
            }
        }
    }
}

planet_event = {

    title = "event_homing.2.title"
    desc = "event_homing.2.desc"
    picture = GFX_evt_anomaly_overheat
    is_triggered_only = yes
    trigger = {
        fromfrom = {
            has_planet_flag = Homing_Earth_flag

        trigger_event = {

            flag = homing_earth_investigating

    }
}
