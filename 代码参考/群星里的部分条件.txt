-----代码覆盖相关-----
MOD与MOD之间使用了原版同一个文件里的某些代码时，可能不会发生冲突（你得自行行查找是否冲突），但使用同一代码时，它们之间必定冲突（举个例子，双方都修改了某一个条件，根据MOD的覆盖特性，某一方的代码将不会生效，这时会影响到其相关代码的执行），如果想要进行适配的话需要双方或是单方自行观看对方覆盖代码进行修改（不想适配也行，没人说必须要适配，除非俩MOD之间想要同时可以顺利进行加载，那就得必须做适配了）
在群星这个游戏里，基本上所有能进行再编写的文件里的代码都可以进行覆盖，且新增的自设代码与原设代码是无关的，所以你无法依靠新增代码来对原始代码进行直接性修改，你只能覆盖原版代码，但覆盖有覆盖上的问题，有些文件可以直接把特定东西的整体代码复制到自己的MOD里进行覆盖性修改，有些文件只能将原始txt文件整个拿到自己的MOD里进行覆盖性修改！！！！！！
如果你不会整覆盖就直接把整个txt文件拿过去自行修改其内容和数值，如果你是直接拿取原版的txt文件那么就最好别改它的txt名字了
而如果你确信这个文件内的代码是可以以单独的某个东西整体的代码直接拿出去进行覆盖，那你也可以单独拿这个文件内的某个整体代码进行覆盖
比如你可以直接将原版某个建筑文件里的整体代码直接迁移到自己的文件里进行覆盖性修改，不知道可以不可以单独拿出来覆盖就自己去试一遍，这是最快的办法
如何知道你要修改的东西是否可以覆盖？那你可以直接去创意工坊里找对应的MOD或者是大型MOD，或者你可以去群里问群友（别傻乎乎的跑去问这个代码该怎么覆盖编写什么的【注：我覆盖和大型MOD玩的少建议你去问问别人有没有见过】，你就直接问有没有MOD可以突破原版的数值或者是修改原版的东西，你问到了就去搜这个MOD，你看它是怎么写的你就怎么写）

-----星系与恒星与行星相关-----
1：如何做到让初始恒星系只能由某个起源使用？以破碎之环
(shattered_ring_start)为例，破碎之环这个星系的代码里有着名为usage = origin的代码，它将初始恒星系变为了只能由起源选择的星系，这样你就无法以正常手段选择这个星系了，然后你在你的起源里加入
initializers = { shattered_ring_start }
代码并在大括号内填入你的初始恒星系的名字就能让这个起源锁定这个星系并且让星系只能由这个起源使用，别人也选不了这个星系
2：星系内的星球不能太多，不然点进星系后会造成游戏直接卡退
3：initializers = { shattered_ring_start }
内代表着这个起源只能在这一个星系内选择，也就是说这个起源只能使用这个星系，但其实initializers内能写入多个星系，例如：initializers = { xxx_1 xxx_2 }，那么这个起源就是只能在xxx_1和xxx_2内进行选择，也就是现在这个起源只能在这两个星系内选择一个当你的初始恒星系（你仍可以在initializers内写更多个，注：未测是否含有限制数量，但一般写几个不是问题）
4：星系中有时某些行星会有资源可以进行收集，而这些资源其实是地块，需要你自己用代码把地块加到行星上去，它才会有资源产出，如果你不知道地块是什么那就去学
5：星系中有时会有土著，想给你的星系上的某个行星上加土著你可以参考原版的天津四星系，或是那个母星有一个土著行星的起源（注：这个起源的土著如果它的星系文件里没有写土著相关代码的话可能是由事件加上去的）

-----舰船与武器相关-----
1：你自己写的舰船会缺少部分武器部件，这是正常的，因为原版代码里的武器部件写了一堆硬性条件，而条件里肯定不包含你的舰船，所以你就没法用，你的舰船部件里就会显示错误，你想让其变得正常就得自己补齐对应的部件（自己再写一套），如果部件写了但舰船里还没有显示要么是你部件写错了，要么是你游戏没重启
2：自建的舰船所需要的最基本的条件为你的舰船部件齐全且拥有至少一个正在启用的区段，如果都有了还造不了那估计是你条件代码写的有问题
3：部分舰船是没有隐形功能的，所以你装上隐形部件也无法将其隐形，但可以另辟蹊径，你使用任何方法让舰船获得隐形BUFF，再使用代码就可以将其强行隐形（有可以解除舰船隐形的代码）
正常舰船隐形所需的条件：需要有隐形BUFF（你可以看原版隐形部件，此为必要条件）而隐形按钮有些是使用专属的隐形装备（武器里写的set）
4：每个武器都是自带-100%的护甲穿透，武器穿透，船体伤害等等，所有如果你想让武器的护甲穿透变成100%，你就得写200%的BUFF，如果想让穿透变成-50%，那就得写50%的BUFF来让其与-100%进行抵消
5：舰船的区段武器部件需要点位攻击特效才能正常的从舰船那里出现，而如果你不懂建模的话点位是可以靠代码制作的，在entity里定义的locator的name值，直接给插槽的locatorname用就行了，如果你不懂 X Y Z 的话，那么position

random_list
将内部的内容进行随机选择一个进行执行，案例
random_list = {
    10 = {
       random_system = {
          limit = { has_owner = no }
          spawn_system = { initializer = "scion_fallen_1" }
       }
    }
    10 = {
       random_system = {
          limit = { has_owner = no }
          spawn_system = { initializer = "scion_fallen_2" }
       }
    }
}
这里的10的意思为拥有10%的几率触发其内部的代码
